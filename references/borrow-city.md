# 借道邻近城市（**正常候选之一**，不是兜底）

> 参考资料 · **借道邻近城市**（正常候选之一）：邻市怎么选、末班车怎么校验、接驳段要写全什么。
> **什么时候读**：只要出发地/目的地**周边有邻市**且存在**跨市轨道 / 公交 / 机场专线**连通，就**要读它并算一遍**——它是一类正常候选，**不要求"目的地到不了"**。

## 借道邻近城市（**每次都算**；末段走跨市公共交通，常常最省）

**它是一类正常候选，不是兜底**——**不要等"别的都失败了"才算它**。末段走**跨市地铁 / 城际铁路 / 跨市公交专线**，单价比"再飞一程 / 再坐一程铁路到小站"**低得多**、班次也多得多，所以借道**经常是最省钱、甚至最快的那一条**；把它当兜底，等于直接把更优解漏掉。

**什么时候跳过**：只有**周边确实没有可用邻市**、或**目的地与邻市之间没有确定的跨市公共交通**时才不算。

**下面这些情形尤其要算**（前三条是过去"到不了"时才想起它的场景，第四条是**最容易漏掉的更优解**）：
- ① **目的地无铁路车站**（或车站无合适车次），或**无机场**且"最近的机场"也无直飞 / 中转；
- ② 到目的地的**直达与自拼中转全部无票**（此时**即使买长乘短 / 补票成立，也要算一次借道**，再按下面的判据与兜底方案比）；
- ③ 到目的地**当日班次极少**（如仅 1–2 趟）且余票**不足 X 人**；
- ④ **邻市是大枢纽、目的地是小站**——大枢纽班次多、票价低，末段跨市地铁/公交单价极低，**借道往往又便宜又快**（这一条与"到得了到不了"无关，纯比价就该算）。

**做法**：把终点从"目的地的站 / 机场"换成**邻近城市**——先按正常口径算到该邻市，再用**跨市城市交通**接到目的地（如 去东莞 可借道 深圳 / 广州 / 惠州）。

- **邻近城市怎么选（硬性，不许随手挑一个城市）**：按「**地理邻近** + **有跨市轨道 / 公交连通**」两条选，列 **1–3 个候选**，每个候选各算一次"到该市 + 该市→目的地"，再比总耗时与总费用。**优先序**：
  1. **跨市地铁**（如 广佛线、上海 11 号线花桥）；
  2. **城际铁路**（如 穗深城际、莞惠城际）——**这一段按铁路办**：用 `12306.js tickets` 查余票与票价、逐段定席别；
  3. **跨市公交专线**；
  4. **机场专线大巴**（邻市机场 → 目的地）。
- **只认有确定线路的公共交通（硬性）**：自驾、跨城打车、顺风车**一律不做**；长途大巴**不进方案**，仅在无任何轨道 / 专线可选时在聊天里一句提示。
- **换乘预留照样要校验**：铁路段 → 跨市段的换乘，**同名站内换成（如 深圳北站 → 深圳北地铁站）按「同站换乘 ≥30 分钟」**，**需出站转场同样看到站后余量 ≥30 分**（口径同「换乘时间规则」：一律 ≥30 分合格 / 20–29 分标红 / <20 分排除，**同站与异站同一标准**）。
- **末班车校验（硬性，不做等于给出一条走不通的方案）**：跨市地铁 / 城际 / 公交**末班收得早**（不少线路 22:30–23:00 前后即收车），**必须校验到达邻市的时刻 + 接驳耗时早于末班发车**；接不上则**换更早的班次**，仍接不上则该借道方案**排除**。校验依据要写进方案（如"末班 23:00，本方案 21:40 抵达，成立"）。
- **接驳段写法**：**按「输出格式要求 → 换乘 / 接驳段必须写具体」写全五项**（线路名称与编号 / 上车站名 → 下车站名 / 途经站数 / 单程票价 / 耗时），首末班与发车间隔也要写。
- **接驳段要参与拼链就得给代码**：把跨市段**按 brief 格式手写成一个腿文件**（头行 `# 上车站 → 下车站  日期`，车次行 `线路名  上→下  发时→到时  历时  席别价格/余票`），再和铁路腿一起交给 `plan.js compose`——**席别名要用 `硬座`（普速口径）**，否则席别裁决认不出、这一腿会被当成无票。手写腿的详细格式见 `SKILL.md → plan.js 用法 → compose`。
- **反例（不许这么写）**：「先到深圳，再想办法去东莞」「邻市换乘约 1 小时」——**客户拿不走**。

**口径与归位（硬性）**：
- **终点写"目的地"并标明走法**（如"东莞 · 经深圳北"）——**不许只写到"深圳北"就当成了到东莞**；
- **总耗时 / 总费用必须含这段接驳**，费用按「方案生成 → 所有方案通用」的**口径逐项列出**，接驳单列一行；
- **参与三段归位**：与其它方案按**各自写明的终点**比较，**进得了"最省钱 / 最快 / 额外"才作为正式方案**；进不去就**不列**，只在聊天里一句说明。
- **判据（与「12306.js 用法 → 中转必须自己枚举枢纽逐腿拼」同一口径）**：借道方案只要比"直达无票后的兜底方案"（买长乘短 / 补票）**更便宜、更快，或同价同速下能给出座位（兜底是无座）**，就**必须采用它**——兜底是最后手段，不是首选。
- **不顺手扩展别的方案**：非借道方案**仍按「方案生成 → 所有方案通用」算到站 / 到机场为止**，**不要**给它们补到达端接驳——那会让两侧口径又变得不可比。

**依据**：跨市地铁与公交**通常不限余票、单价极低**，所以借道不只是"到目的地全线无票"时唯一还走得通的路子——**它本身就常常是最省、甚至最快的一条**，属正常候选，不是将就。
