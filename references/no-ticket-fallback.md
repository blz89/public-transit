# 无票兜底（买长乘短 · 补票）

> 参考资料 · **无票兜底**：回转 / 买长乘短 / 补票 / 拼票的触发条件与做法。
> **正常流程不要读它**——只有"起点站无票"或"该车次全部席别无票"时才读。

## 无票时的多买策略（买长乘短，需提醒；兜底条款）

- **适用场景**：想从起点站出发，但该站出发的指定车次已无票；同一车次从**更早一站**买票到目的站仍有票时，可"多买一站"获得从起点站上车的资格。
- **多买原则**：多买的区间**必须尽可能便宜**——优先选起点站的**前一站**（相邻站，票价增量最小）；只多买必要的区间，不跨多站。
- **提醒义务**：给出此类方案时，**必须明确提醒**："多买一站，从更早的 X 站上车（该区间票价计入成本，实际仍从起点站上车），多付 N 元；车票区间起点在前，可正常从中间站进站上车。"
- **成本口径**：总费用 = 多买区间的票价（含起点站到目的站），并单独标注"多付 N 元（多买区间）"。
- **不可行情形**：若前一站也无票，或车次不经过起点站，则不要用多买策略，改为换车次/中转/空中方案。
- 示例：D3792 田东北无票，但同一 D3792 从更早的「平果」到南宁有票，则可买「平果→南宁」区间、实际从田东北上车，多付平果→田东北这一小段票价。

## 极端无票时的补票策略（买短乘长 · 补票段无座，需提醒；兜底条款）

**只在极端无票时启用**：出发当天该车次**我们考虑的全部席别都没有可用余票**（席别范围见「席别规则」；**只剩商务座 / 特等座也算无票**——此时该列车**不列入方案**，不能当成"有票可选"），**且**其它车次 / 日期 / 空中方案都不成立（或用户明确要求当天必须走）时，才考虑用它走人。

- **做法**：**先买一张能上车的短途票（买短乘长）**——买"起点站 → 中途某站"这一段，上车后向列车工作人员**补票**延长到目的站；**补票那一段是无座**（不保证有座）。
- **前置校验（硬性，缺一不可）**：必须先**另查该车次"起点站 → 中途站"这段更短区间的余票**，**确认买得到这张短途票**，补票策略才成立；查不到有票的短区间 → **不成立**，**不得**凭空假设"先上去再补"。
- **必须同时给出（四项缺一不可）**：
  1. 明确标注「**补票上车 · 补票段无座**」——与"直接买无座票"**明确区分**；
  2. **超员风险提示**：部分列车（**复兴号、部分动车组**）**不允许超员**，可能**拒绝补票**或要求**在前方站下车**；补票可能加收手续费；**因此无座段不得作为唯一方案**；
  3. **备选**：同时给出改其它车次 / 改日期 / 空中方案的可行项，让用户自己权衡；
  4. 一句话说明"**这是极端无票下的兜底，不是常规推荐**"。
- **与「无座票规则」的关系**：本策略是**超过门槛时长**时无座的**唯一**出现形式；**门槛以内**的短途不适用本策略，直接按「无座票规则」正常处理。
- **与「买长乘短」的区别（别混用）**：「买长乘短」是**起点站无票、更早一站有票** → 买更早一站、**有座**、优先；本条是**所有席别全无票** → 只买到中途站、**补票段无座**、兜底。
